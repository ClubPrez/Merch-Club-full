Tasks:

1. Feed URLs:
   Any old feed URL should return 410 Gone if possible, otherwise 404.
   This includes:
   - /product/*/feed/
   - /comments/feed/
   Do not redirect feed URLs to homepage or /services.

2. WordPress/plugin/WooCommerce technical URLs:
   Return 410 or 404 for:
   - /wp-includes/*
   - /?wc-ajax=*
   - /locations.kml
   Do not include them in sitemap.
   Do not block them in robots.txt if already discovered; Google should be able to crawl and see 404/410.

3. Old product URLs:
   For known product/service URLs that represent real services Merch Club still offers, 301 redirect them to /services, or to a more specific current service page if one exists.
   Avoid broad catch-all redirects for unknown /product/* URLs.
   Known old product URLs may redirect to /services.
   Unknown product URLs should return 404/410.

4. Old product-category pagination:
   Return 410 or 404 for old paginated category URLs such as:
   - /product-category/emblem/page/3/
   - /product-category/custom-shirts/page/2/
   - /product-category/custom-shirts/page/3/
   - /product-category/custom-shirts/page/4/

   If /product-category/custom-shirts/ itself has already been redirected to /services, keep that redirect, but do not redirect old pagination pages unless there is a strong reason.

5. Current pages:
   Check /gallery and /latest-catalogs.
   These should be real 200 OK pages if they exist on the current site.
   Make sure they:
   - return 200 OK
   - are not noindexed
   - have canonical tags pointing to themselves
   - appear in sitemap only as final canonical URLs
   - are internally linked using the final URL format

6. Sitemap cleanup:
   Make sure sitemap.xml includes only final 200 OK canonical URLs.
   Remove:
   - old /product/* URLs
   - old /product-category/* URLs
   - feed URLs
   - wp-includes URLs
   - wc-ajax URLs
   - locations.kml
   - redirected URLs
   - 404/410 URLs

7. Internal link cleanup:
   Search the codebase for:
   - /product/
   - /product-category/
   - /feed/
   - /comments/feed
   - wp-includes
   - wc-ajax
   - locations.kml
   - latest-catalogs
   - gallery

   Update or remove internal links that point to obsolete URLs.
   Keep internal links to /gallery and /latest-catalogs only if they are current live pages.

8. Canonical cleanup:
   Make sure canonical tags use:
   https://merchclub.com
   and point only to final 200 OK pages.

9. Redirect/status rules:
   Keep server-side Vercel rules as the source of truth for Googlebot.
   Client-side SPA redirects are okay as backup, but they do not replace server-side redirects/statuses.
