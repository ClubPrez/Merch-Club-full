1. visually show an animated “AI scanning” process in the front end
2. actually fetch and inspect the submitted website in the backend
3. attempt to find the business logo from the website
4. extract some basic brand cues like company name and possible colors
5. place the detected logo onto 3 merch mockups that I will provide as image/template assets
6. reveal the final mockups in a polished results state
7. capture the lead with a form after the mockups are shown

REAL BACKEND FUNCTIONALITY

WEBSITE SCRAPING
When the user submits a URL, the backend should:
1. normalize the URL
2. fetch the homepage HTML
3. parse the page
4. try multiple strategies to find the logo

LOGO DETECTION STRATEGY
Attempt these in order:
- look for img elements with class/id/alt/src containing “logo”
- inspect header/navbar brand images
- inspect Open Graph / social image tags if useful
- inspect favicon or site icons as fallback
- inspect SVG logos if possible
- resolve relative image URLs to absolute URLs

Choose the best candidate logo using heuristics:
- prioritize images with “logo” in alt/class/src
- prefer transparent PNG or SVG when possible
- avoid tiny icons if a better logo exists
- avoid obvious hero images or banners
- fallback gracefully if only favicon is available

COMPANY NAME DETECTION
Derive company name from:
- meta title
- og:site_name
- title tag
- domain parsing fallback

BRAND COLOR DETECTION
Try to derive likely brand colors from:
- logo image dominant colors
- CSS variables or theme colors in page source
- favicon/logo palette fallback
- if no good result, generate tasteful fallback colors

MOCKUP GENERATION
I will provide 3 mockup template assets.
Use those assets and programmatically place the extracted logo onto each mockup.

IMPORTANT MOCKUP REQUIREMENTS
- preserve realistic placement
- resize logo intelligently for each mockup
- keep aspect ratio
- add padding
- if logo background is not transparent, handle it as cleanly as possible
- center or place logo in the correct predefined print area
- use different placement rules per product type

Assume I will attach mockup assets such as:
- bottle mockup
- hoodie or quarter zip mockup
- hat or mug mockup

Create a backend image compositing pipeline that:
- downloads the detected logo
- preprocesses it if needed
- overlays it onto each template
- exports final generated mockup images
- returns URLs/paths for those generated assets

IMAGE PROCESSING
Use a reliable Node image library for compositing, such as sharp, if possible.
Create a reusable configuration object for each mockup that defines:
- template source
- print area x/y
- max width
- max height
- placement style
- optional rotation if needed

If background removal is not available, assume best-effort placement.
If the extracted logo is poor quality, still continue and show a fallback state.

Build graceful fallback behavior.

If scraping fails:
- still show the scanning UI
- display a friendly fallback message
